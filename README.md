# 배움마을

Next.js와 Phaser로 만든 교육용 웹 게임 프로토타입입니다.

## 현재 구현

- 키보드 방향키/WASD와 터치 조이스틱으로 월드 이동
- 중앙 분수대 시작
- 3개 건물의 근접 상호작용
- 좌측 상단 `생활 속 AI 가게`에서 첫 번째 미니게임 실행
- 관광객·농부·의사 등 무작위 손님 6명의 부탁 해결
- 난이도에 따라 3→4→5개로 늘어나는 AI 도구 진열대
- 도구 전달·문제 해결 전후 연출, 부드러운 오답 학습 피드백
- 연속 정답 콤보와 별 결과
- PNG 파일 교체형 에셋 구조

## 콘텐츠 수정

12개의 생활 속 AI 문제와 답은 `src/game/content/questions.ts`에서 바꿉니다.
그림 교체 규격은 `public/assets/README.md`에 정리되어 있습니다.

## 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.
