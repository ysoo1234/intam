# 전문가 역할과 협업 계약

## 0. 총괄 아키텍트

- 작업 우선순위, 모듈 경계, 성능 예산을 결정한다.
- 전문가별 변경 범위를 배정하고 통합 충돌을 해결한다.
- 정확성·성능·검증 관문을 모두 통과한 변경만 병합한다.
- 현재 담당: Codex 총괄 에이전트.

## 1. 런타임·성능 전문가

- Next.js 번들, Phaser 부팅, 씬별 로딩, 프레임 시간, 메모리를 계측한다.
- 사용자 의도 기반 lazy load와 bounded prefetch 정책을 소유한다.
- 최적화 전후 수치와 동일 동작 근거를 남긴다.

## 2. 맵·게임 시스템 전문가

- 월드/맵 schema, 카메라, 충돌, 입력, 씬 수명주기를 소유한다.
- 미니게임 규칙과 상태 전이를 Phaser 표현 코드에서 분리한다.
- 동일 seed 재현성과 저장 데이터 호환성을 지킨다.

## 3. 프런트엔드·접근성 전문가

- React 셸, 로딩/오류 상태, 반응형 레이아웃, 키보드·터치 접근성을 소유한다.
- Client Component 경계를 최소화하고 불필요한 재렌더를 막는다.
- 게임 캔버스 밖의 제품 UI가 엔진 상태를 직접 수정하지 않게 한다.

## 4. 콘텐츠·게임 기획 전문가

- 학습 목표, 난이도 곡선, 보상, 대사, 문제 데이터의 일관성을 소유한다.
- 콘텐츠는 코드 분기보다 검증 가능한 데이터 계약으로 만든다.
- 기술 최적화가 교육 의미나 게임 밸런스를 훼손하지 않았는지 확인한다.

## 5. 비주얼·에셋 파이프라인 전문가

- 원본, 편집본, 배포용 파생 에셋을 분리한다.
- 해상도, 알파, 압축, atlas, 파일명과 라이선스 메타데이터를 관리한다.
- `public/assets`에는 실제 참조되는 최적화 결과만 승격한다.

## 6. 플랫폼·데이터·보안 전문가

- 저장, 동기화, API, DB, 인증이 추가될 때 서버 경계를 소유한다.
- schema migration, 트랜잭션, 캐시 수명과 권한 검증을 관리한다.
- 쓰기 요청의 사용자·역할·공간 소속을 서버 세션에서 검증한다.

## 7. QA·관측 전문가

- 핵심 흐름, 회귀, 화면, 에셋 누락, 성능을 독립적으로 검증한다.
- 구현팀의 내부 값이 아니라 사용자 관측 결과를 근거로 판정한다.
- 실패를 조용히 삼키지 않고 재현 정보와 함께 보고한다.

## 작업 배정 원칙

- 한 변경에는 한 명의 주 소유자와 한 명의 독립 검증자를 둔다.
- 공통 파일보다 기능 소유 폴더를 우선 수정한다.
- 최적화는 `측정 -> 변경 -> 동일 동작 검증 -> 예산 반영` 순서로 진행한다.
- 원본 이미지와 임시 생성물은 배포 디렉터리에 두지 않는다.
