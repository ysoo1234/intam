# 미디의 윤리 심사소

초등학교 6학년이 창구로 찾아온 친구들의 `AI 사용 확인서`를 읽고 승인 또는 거절 도장을 찍는 2분 게임이다. 2026-10-05에 빈 벽·카드·도장만 있던 정적인 구성을 사무실 창구 장면으로 재설계했다.

## 장면 구성 (1280×720)

- 배경은 `inspection-booth-v2`(창구·서류장·책상)이며 좌표는 `scene/layout.ts`가 단일 원천이다.
- 왼쪽 위 창구(아치 76,62 318×268)에는 AI 공방의 학생 손님 원화(`customers/v3-game/*-worried/-happy`) 한 명이 전신으로 서고, Phaser 4 마스크 필터(`filters.external.addMask`, Canvas는 geometry mask)로 창틀에 맞춰 잘린다. 손님은 복도 왼쪽에서 걸어 들어오고 같은 방향으로 나간다. 도장이 맞으면 기쁜 표정 원화로 바뀐다. 학생 6명(도윤·하린·서아·유나·지후·민서)이 순서대로 교대한다.
- 미디는 책상 뒤 통로(x 850, 발 y 342, 높이 196)에 서서 손님이 오면 창구 쪽을 잠깐 바라본 뒤 정면을 본다. 숨쉬기 보브와 도장 반응(점프/흔들림)은 `ethicsReviewPlayer.ts`가 소유한다.
- 확인서(`inspection-form-v2`, 500×300)는 창구 선반(330,352)에서 책상 가운데(830,462)로 미끄러져 들어오고, 도장 자국을 안은 채 다시 창구로 돌아간다. 왼쪽에 주제 삽화와 주제명, 오른쪽에 두 줄 상황문(29px, 긴 문장은 24px까지), 아래에 `신청인 이름 · AI 사용 확인서`.
- 도장 2개는 책상 앞 모서리(466,644)/(1190,644)에 놓이고 아래 색 명판에 `승인`/`거절`을 표시한다. 클릭/터치 또는 ←/A, →/D 키.
- 창구 아래 캐비닛에는 `AI 사용 심사 기준` 5줄 패널이 있고 현재 확인서의 주제가 강조된다.
- 상단은 다른 미니게임과 같은 공통 크롬(마을로 돌아가기 버튼, 4칸 상태 패널: 손님 수·점수·콤보·남은 시간/연습).

## 흐름

1. 시작 안내 → 연습 1장(시간 제한 없음). 틀리면 미디가 말풍선으로 이유를 설명하고 `한 번 더`, 맞히면 `2분 심사 시작`.
2. 실전은 실제 120초. 확인서 도착(340ms) 뒤부터 입력을 받고, 도장은 150ms 들어 올려 200ms 날아가 75ms에 내려찍는다(타격 375ms에 효과음·미디 반응·손님 말풍선·점수 상승 표시를 맞춘다).
3. 정답 1.5초, 오답 3초 뒤 확인서와 손님이 나가고(220ms) 다음 손님이 온다. 오답에는 미디 말풍선이 해설을 보여 주고 확인서에는 `다시 생각!` 자국이 남는다.
4. 3·5·8·12연속 정답에 짧은 축하 문구와 효과음. 정답 100점 + 연속마다 10점(최대 150점).
5. 별 2개는 정답 6장·정확도 60%, 별 3개는 정답 12장·정확도 80%. 결과 화면은 손님 수·정확한 판정·정확도·점수·최고 연속을 보여 준다.

## 소유 범위

- `model/`: 덱 구성, 판정·점수·콤보·별, 손님 교대 규칙, 연습/실전 상태 전이. Phaser를 import하지 않는다.
- `content/`: 40개 사례(주제별 승인 4·거절 4), 연습 사례, 심사 기준 라벨, 손님 2명과 짧은 대사.
- `scene/`: 사무실·심사 기준 패널(`ethicsReviewOffice`), 창구 손님(`ethicsReviewVisitor`), 확인서·도장(`ethicsReviewView`), 미디(`ethicsReviewPlayer`), 도장 연출(`ethicsReviewEffects`), 입력(`ethicsReviewControls`), 효과음(`ethicsReviewAudio`), 결과(`ethicsReviewOverlays`), 조립(`EthicsReviewScene`).

## 그림

손님은 1번 게임과 같은 출연진·그림체를 쓴다. 도장·확인서·추가 학생을 같은 그림체로 새로 생성할 때의 프롬프트·규격·파일명·연결 방법은 `assets-source/ethics-review/office-redesign-image-requests.md`에 있다. 그림을 교체할 때는 `src/game/assets.ts`의 `ethicsReview` 경로와 `scripts/optimize-game-assets.mjs` 항목만 바꾸면 된다.

이전 도장 무대(`stamp-stage-v2`)·간소화 창구·배달 시안 원화와 생성 기록(`stamp-*.md`, `inspection-generation-notes.md`, `simplification-generation-notes.md`, `delivery-generation-notes.md`)은 비교·복구용으로 보존한다.
