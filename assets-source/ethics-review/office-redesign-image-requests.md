## ① 학생 손님 추가 (한 명씩, 걱정/기쁨 2장 세트)

창구에는 한 번에 한 명만 선다. 한 명당 `걱정`(들고 와서 기다리는 얼굴)과 `기쁨`(도장을 받고 좋아하는 얼굴) 두 장이 필요하다. **먼저 걱정 컷을 뽑고, 그 결과를 첨부해서 기쁨 컷을 편집**해야 같은 아이가 나온다.

- 규격: 세로 2:3 (1024×1536 권장), **배경 완전 투명(알파)**, 전신, 발까지 보이게, 사방 8% 여백. 게임은 454×680 캔버스·발 y 642 기준으로 맞추므로 발 위치는 아래 가장자리 근처로.
- 파일명: `assets-source/customers/v3-game/<request-id>-worried.png`, `<request-id>-happy.png` (예: `ethics-visitor-01-worried.png`)

걱정 컷:

```text
한국 초등학교 6학년 학생 한 명을 전신 정면으로 그려줘. 양손으로 크림색 서류 폴더를 가슴 앞에 들고, 창구 앞에서 심사를 기다리며 살짝 걱정되는 표정(눈썹이 조금 처지고 입을 작게 다문 얼굴). 발끝까지 전부 보이게, 그림자나 바닥은 그리지 말고, 배경은 완전히 투명한 PNG로(체크무늬나 흰 배경 없이). 글자 없음.
학생 설명: {학생 설명}
```

기쁨 컷 (걱정 컷 첨부):

```text
첨부한 아이를 그대로 유지하면서 표정과 손만 바꿔줘. 활짝 웃으며 눈이 초승달 모양으로 감기고 볼이 발그레한 기쁜 얼굴, 폴더를 가슴 앞에서 조금 들어 올린 모습. 옷, 머리, 비율, 색, 윤곽선, 캔버스 크기, 발 위치는 입력과 똑같이. 배경은 완전히 투명하게, 글자 없음.
```

`{학생 설명}` 예시:
1. `양갈래로 묶은 머리의 여자아이, 노란 카디건과 흰 티셔츠, 파란 치마, 흰 운동화`

4. `곱슬머리 남자아이, 주황색 체크 셔츠, 남색 바지, 작은 초록 가방`

## ② 도장 2개 (승인·거절) — 같은 그림체로

지금 도장(`stamp-tool-*`)은 외곽선이 굵고 입체적이라 손님 그림체와 어긋난다. 그림책 느낌의 부드러운 도장으로 바꾼다.

- 규격: 정사각 1024×1024, **배경 완전 투명**, 도장이 캔버스의 약 80%, 바닥면 수평, 그림자 없음. 게임 표시 150×138.
- 파일명: `assets-source/ethics-review/office-stamp-approve-v1.png`, `office-stamp-reject-v1.png`

```text
어린이 그림책 느낌의 고무 도장 하나를 정면 약간 위에서 본 각도로 그려줘. 둥근 나무 손잡이는 {색}이고 윗면에 부드러운 파스텔 하이라이트, 손잡이 아래에 크림색 받침 띠, 바닥은 아이보리색 직사각형 고무 밑면이야. 밑면 앞쪽에 {기호}가 보이는 작은 둥근 명판이 있어. 얇고 부드러운 갈색 윤곽선과 종이 질감 파스텔 채색으로, 입체적인 광택이나 두꺼운 검은 선은 쓰지 마. 바닥면은 완전히 수평, 그림자 없음. 배경은 완전히 투명한 PNG(체크무늬·흰 배경 없이 도장만). 글자 없음. 정사각 캔버스에 도장이 약 80%를 차지하게.
```

- 승인: `{색}` = `연한 민트색`, `{기호}` = `흰색 체크 표시`
- 거절: `{색}` = `연한 코랄색`, `{기호}` = `흰색 X 표시`

체크무늬가 "그려져" 온 경우(진짜 투명이 아닐 때) 그 이미지를 첨부해 한 번 더:

```text
이 도장 이미지의 배경을 제거해서 진짜 투명 알파 PNG로 만들어줘. 회색과 흰색 체크무늬는 전부 배경이야. 도장 자체는 색, 윤곽, 형태 그대로 유지하고 도장 바깥만 완전히 투명하게.
```

## 생성 뒤 할 일

1. PNG를 위 파일명으로 저장한다. 학생은 `assets-source/customers/v3-game/`, 나머지는 `assets-source/ethics-review/`.
2. `scripts/optimize-game-assets.mjs`의 `ASSETS`에 항목을 추가한다. (`customers/v3-game/*.png`는 폴더를 통째로 읽으므로 추가 작업 없음.)
   - 도장: `highDpiPanelAsset({ source: "ethics-review/office-stamp-approve-v1.png", trim: true, quality: 96, alphaQuality: 100 }, { width: 160, height: 150 })`
   - 확인서: `highDpiPanelAsset({ source: "ethics-review/office-form-v1.png", trim: true, quality: 96, alphaQuality: 100 }, { width: 510, height: 306 })`
   - 미디: `characters/midi_*` 항목과 같은 규격(230×295), 게시판: 300×236.
3. `npm run assets:optimize -- office-`로 WebP를 만들고, `npm run assets:audit`가 알려 주는 크기·알파를 `scripts/audit-game-assets.mjs`의 `RUNTIME_SPECS`에 적는다.
4. 코드 연결:
   - 새 학생: `src/game/assets.ts`의 `ethicsReview.visitors` 아이디 배열, `src/game/features/ethics-review/model/types.ts`의 `EthicsVisitorId`, `content/cases.ts`의 `ETHICS_VISITORS`(아이디·이름)에 추가하면 교대 규칙이 자동으로 순환한다.
   - 도장·확인서·게시판·미디: `assets.ts`의 `ethicsReview.stampApprove/stampReject/form` 경로만 바꾸면 된다(게시판·미디 포즈는 코드 연결이 더 필요하므로 파일을 넣고 요청).
5. `npm run verify`.
